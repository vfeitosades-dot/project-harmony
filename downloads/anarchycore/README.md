# AnarchyCore — Plugin Paper (Beta)

Arquivo: `AnarchyCore-1.0.0-beta.jar`

**Status:** beta experimental. O JAR contém classes Java compiladas, mas foi construído com uma API de validação local e **ainda não foi testado iniciando em um servidor Paper 1.21.11 real**. Faça backup do seu servidor e teste primeiro em um ambiente separado.

**Instalação:** coloque o JAR na pasta `plugins/` do Paper, reinicie e consulte o console. Se carregar, use `/ac status`.

**Requisitos previstos:** Minecraft Paper 1.21.11 e Java 21.
