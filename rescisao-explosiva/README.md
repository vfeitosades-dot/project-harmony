# Rescisão Explosiva

Jogo de plataforma sobre Zé, um trabalhador CLT demitido de uma fábrica de chocolate. Use o recuo da bazuca para voar, resolver puzzles e enfrentar dois chefes em seis setores.

**[Baixar o projeto para GameMaker (.yyz)](https://github.com/vfeitosades-dot/project-harmony/raw/refs/heads/main/rescisao-explosiva/RESCISAO_EXPLOSIVA.yyz)**

No GameMaker, escolha **Import Project**, selecione o `.yyz` e extraia em uma pasta nova. Alvo principal: Windows, teclado e mouse. Referência de versão: GameMaker 2024.11 ou posterior.

- A/D ou setas: mover.
- Mouse: mirar; botão esquerdo: disparar.
- Mire no chão para subir e encadeie tiros no ar.
- R: retornar ao checkpoint. Esc: pausa. M: som. F11: tela cheia.
