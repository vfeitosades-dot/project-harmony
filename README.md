# VÉRTICE — Protocolo Zero

FPS tático solo offline, com arte e modelos originais, feito em Godot 4.6.3.

## Baixar e jogar

**[Baixar o jogo para Windows (ZIP)](https://github.com/vfeitosades-dot/project-harmony/raw/refs/heads/vertice-downloads/Downloads/Vertice-Windows.zip)**

Extraia o ZIP e abra `Vertice.exe`. Não precisa instalar Godot.

[Todos os arquivos da versão](https://github.com/vfeitosades-dot/project-harmony/releases/tag/vertice-v0.1.0)

## Conteúdo

- Arena 3D com coberturas e rotas laterais.
- Rifle automático, recarga, headshots, vida e escudo.
- Bots, radar, dash e pulso de reconhecimento.
- Três operações: elimine os sentinelas e segure F no reator para desarmá-lo.

WASD: mover · Mouse: olhar/atirar · Botão direito: mirar · R: recarregar · Espaço: pular · Shift: andar · Q: dash · E: pulso · F: desarmar · Esc: pausa · F11: tela cheia.

## Projeto e validação

Importe `project.godot` no Godot 4.6.3. Para exportar, instale os templates oficiais no editor.

Protótipo original inspirado em FPS táticos. Sem afiliação com a Riot Games e sem recursos extraídos de Valorant. Não inclui multiplayer.

Testado em Godot/Linux, incluindo a versão exportada. O executável Windows x64 foi gerado e inspecionado, mas não executado em Windows real. Consulte `LEIA-ME.txt` para detalhes, referências e limitações.
